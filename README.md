# Espirito Santo Open Data (dados-es-gov-br)

Espirito Santo Open Data is a state government open-data portal for Brazil running **CKAN** (~452 datasets).

**URL:** [https://raw.githubusercontent.com/api-evangelist/dados-es-gov-br/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/dados-es-gov-br/refs/heads/main/apis.yml)

## API
- Base: `https://dados.es.gov.br/api/3/action` · [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://dados.es.gov.br)
